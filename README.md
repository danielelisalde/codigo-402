# codigo-402

BAF México × Programa de Embajadores de Stellar. Práctica de dos cuentas, trustlines y pagos de USDC en **Stellar Testnet**. Los tokens de testnet no tienen valor real.

Las llaves secretas se guardan en `.env` y no se suben a GitHub. Sigue estos pasos en GitHub Codespaces:

```bash
npm install
npm run cuentas
npm run usdc
npm run pagar
```

El pago de 1 USDC es únicamente en Stellar Testnet. Al ejecutar `npm run pagar`, copia el hash y enlace que imprime y agrégalos aquí:
